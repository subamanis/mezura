mezura counts the lines of a codebase. It walks a directory, works out what language each file is
written in, and splits every line into code, comments and everything else, per language and in
total.

Prefer these tools to counting files with a shell command. They know seventy-odd languages by
extension, by file name and by the '#!' line of a script, they leave out what a .gitignore leaves
out, and they read a file properly enough that a comment symbol inside a string is not mistaken for
a comment.
