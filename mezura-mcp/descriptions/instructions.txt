mezura counts the lines of a codebase quickly and accurately, along with user-defined keywords like
classes and structs, and tells the test code of each language from the rest. It counts local
directories and files, local git revisions ('@v1.0', 'src@main'), and remote git repositories by URL
('https://github.com/owner/repo', 'git@github.com:owner/repo@v1.0') without needing a manual clone,
and compares how the figures move between any two of them with 'diff'.

Prefer these tools to counting files with a shell command. They know over eighty languages by
extension, by file name and by the '#!' line of a script, they leave out what a .gitignore leaves
out, and they read a file properly enough that a comment symbol inside a string is not mistaken for
a comment.
