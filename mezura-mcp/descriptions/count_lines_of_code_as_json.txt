The same count or comparison as 'count_lines_of_code', returned as a JSON document instead of a
report to read.

Use this one only when the numbers are going to be computed on: compared against a limit, added up,
sorted, or written to a file. The document is about ten times the size of the report and carries
only what was measured, so the percentages and the totals that the report prints have to be worked
out of it. For a question somebody is going to read the answer to, use 'count_lines_of_code'.

The test code sits under 'tests' on each language, on 'total' and on each module, with
'whole_files' saying how many of its files are test code from the first line to the last,
'scope.tests_detected' says whether it was looked for at all, and 'scope.test_presets' lists the
test tools whose own file turned their test names on, with the folder and the file, since the
report's list of them is not in this document. A language with no 'tests' key had none found; what
counts as found, and how the rest is declared with 'tests', is as for 'count_lines_of_code'.
