Show one file line by line, with the reason each line was counted the way it was.

Every line is printed with the bucket it landed in, the class mezura read off it, and, where
something was still open when the line began, what that was and where it started: 'in a comment
opened by /* on line 23', 'in a string opened by " on line 7'. A line read as an embedded language
names that language.

Use it when a count looks wrong, or to settle what one particular line is. One file per call.
