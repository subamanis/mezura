Which language wins an extension that more than one of them claims.

Two languages can want the same extension: '.m' is Objective-C to one person and MATLAB to another,
'.pl' is Perl to one and Prolog to another. Only one of them can have it, and the choice matters more
than a label, because the wrong language means the wrong comment symbols, and then every comment line
of the loser is counted as code.

Without a line here, the extension goes to whichever language name comes first alphabetically, and
the program says so on every run so that it is never a silent decision. Write the extension, then the
languages that claim it separated by commas. The first name takes it and the rest lose their claim:

    m       Objective-C, MATLAB
    pl      Perl, Prolog

The names are the ones the language files declare, and neither they nor the extension care about
capitalisation. A language you have removed, or one that never existed, is skipped and the next name
on the line is tried.

Change who wins by reordering the names on a line, not by deleting the line. This file is yours to
edit and is never replaced, so every answer you give here survives an update; what an update does
add is the rules for contests your copy does not mention at all, and a line you removed is one your
copy does not mention. Your copy as it stood is kept under 'replaced' whenever anything is added.

This settles the question for every run. To decide it for one run, or for one project through its
configuration file, use '--force-language', as in '--force-language m=matlab', which overrides this
file.

The four that ship are the only contests the shipped languages have between them, and none of the
four has an answer that is right for everybody:

  h     C Header over C++ Header and Objective-C, whose headers are also '.h' files. There is no way
        to tell them apart from the name. On GitHub, 57 of every hundred '.h' files are C, 42 are
        C++ and 2 are Objective-C, so a C++ project is the swap this line is most often wanted for.
  m     MATLAB over Objective-C. Both are common and neither is close to a majority: 59 of every
        hundred '.m' files on GitHub are MATLAB. Objective-C also answers to '.mm', so it still
        counts the part of a project that is not contested; MATLAB has no second extension at all.
  pl    Perl over Prolog. Prolog also answers to '.pro' and '.prolog'.
  pas   Pascal over Delphi. Delphi also answers to '.dpr' and '.dpk'.

A file known by its whole name, like 'Makefile' or 'CMakeLists.txt', is settled the same way, under
the second marker. Nothing that ships contests a name, so that block is empty and is there for the
languages you add:

    Makefile    Make, Automake

Everything above is explanation and is ignored, exactly as in a configuration file. The rules
are the lines below each marker.

===> contested-extensions
h       C Header, C++ Header, Objective-C
m       MATLAB, Objective-C
pl      Perl, Prolog
pas     Pascal, Delphi

===> contested-filenames
